The adapter is a Native-engine audio fallback for formats the device cannot decode
(DTS/DTS-HD, TrueHD, AC-3/E-AC-3, AAC, MP3, Vorbis, Opus, FLAC, ALAC, AMR, G.711, GSM),
using FFmpeg's built-in LGPL decoders. It
links dynamically to the existing FFmpeg 9.0-series shared libraries in the MPV
runtime; the MPVFlow arm64 build pins n9.0.2. The runtime is built with GPL and
nonfree support disabled, under LGPL-3.0-or-later. It adds no separate FFmpeg decoder
binary.
