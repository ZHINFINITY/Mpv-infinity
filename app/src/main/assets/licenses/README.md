# Additional application third-party notices

The Media3 DTS audio adapter is a separate Apache-2.0 wrapper and reuses the application's existing LGPL-3.0-or-later FFmpeg DCA decoder. Its notices are in `media3/NOTICE.txt` and `media3/APACHE-2.0.txt`. No GPL or nonfree decoder is included by this adapter.

The MPV/FFmpeg runtime notices remain in `../mpv/licenses/`.

Runtime asset notices are packaged under `third-party-runtime/` and cover the
Python 3.13.12 runtime, Go Noto Current-Regular font, and Mozilla-derived CA
bundle shipped inside the MPV AARs.
