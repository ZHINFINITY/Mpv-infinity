# Runtime third-party notices

These notices are packaged in the APK alongside the runtime assets they cover.
The corresponding repository copies are in `THIRD_PARTY_LICENSES/`.

- **Python 3.13.12:** `libpython.so` for each ABI and `ytdl/python313.zip`; the notice includes the complete upstream CPython `LICENSE` from tag `v3.13.12`.
- **Go Noto Current-Regular:** `assets/subfont.ttf` inside both MPV AARs; metadata reports the Noto Project Authors and SIL Open Font License 1.1. The exact AAR build provenance is not asserted beyond those embedded metadata values.
- **Mozilla CA bundle:** `assets/cacert.pem` inside both MPV AARs; the notice records the 2026-07-16 curl/Mozilla bundle date and SHA-256 and includes the complete MPL 2.0 text.
