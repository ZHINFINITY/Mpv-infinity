# FongMi GPU motion interpolation sources

This directory retains the locally adapted FongMi motion core from [FongMi/mpv commit `f0ebca2a2c546444d9f9a62662b2f6e27614f7de`](https://github.com/FongMi/mpv/tree/f0ebca2a2c546444d9f9a62662b2f6e27614f7de/video/out/gpu_next). The upstream progress notes are at [`DOCS/memc-progress.md`](https://github.com/FongMi/mpv/blob/04e9d60470cfac3b407bc8bafcd54e2955e8f761/DOCS/memc-progress.md). Its files retain their LGPL-2.1-or-later SPDX notices; local changes added pre-analysis and caller-owned output-texture paths for the former Media3 integration.

This older helper snapshot is retained with its source attribution, but it is not linked into the restored Native Media3 engine and is not copied into the current MPV runtime. The experimental MPV runtime checks out and builds native FongMi/mpv commit [`14b3999a1a3e322c217bc90ee4df5a8f1bc88f69`](https://github.com/FongMi/mpv/tree/14b3999a1a3e322c217bc90ee4df5a8f1bc88f69) directly. The pinned upstream `video/out/gpu_next/motion.c` receives a version-guarded, app-owned refinement, synthesis, reconstruction, and inverse-warp patch through `scripts/patch_fongmi_motion_artifact.py` before build. It checks local flow coherence at likely seams, attenuates trust at luma/chroma boundaries, extends the color-error trust fade through `0.30`, and caps directional softening to supported moving regions. In strongly anisotropic structure-tensor patches, refinement adjusts only the principal-gradient component while retaining the inherited tangential motion estimate; well-textured and corner patches retain their measured two-dimensional flow. Inverse-warp recovery retains the initial position and updates, then selects the finite candidate with the best forward-closure residual while preserving existing support, cycle, and confidence gates. Unsupported motion retains the source-frame crossfade.

The current test candidate also applies `scripts/patch_fongmi_motion_resolution.py`: its analysis cap is 960 pixels instead of 480, with a fourth pyramid level so the coarsest search range remains about 96 source pixels for 1920-wide input. This halves finest-grid support from about 12 to 6 source pixels on that input, while source-derived workload estimates are roughly 4×; performance still needs verification on the target phone. This is an experiment, not a release change or proof that resolution alone is the only artifact cause. The active pinned source is validated by `scripts/prepare-mpvflow.py`; these transforms do not replace FongMi source. The retained snapshot mirrors safeguards for regression checks but is not the build patch source. FongMi's GPL-2.0 attribution and full upstream `LICENSE.GPL` text remain preserved in `app/src/main/assets/mpv/licenses/` alongside all upstream per-file notices.

Keep this attribution and each source-file notice with the retained code. This branch remains experimental, unmerged, and unreleased.
