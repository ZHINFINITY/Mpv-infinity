# FongMi GPU motion interpolation sources

This directory retains the locally adapted FongMi motion core from [FongMi/mpv commit `f0ebca2a2c546444d9f9a62662b2f6e27614f7de`](https://github.com/FongMi/mpv/tree/f0ebca2a2c546444d9f9a62662b2f6e27614f7de/video/out/gpu_next). The upstream progress notes are at [`DOCS/memc-progress.md`](https://github.com/FongMi/mpv/blob/04e9d60470cfac3b407bc8bafcd54e2955e8f761/DOCS/memc-progress.md). Its files retain their LGPL-2.1-or-later SPDX notices; local changes added pre-analysis and caller-owned output-texture paths for the former Media3 integration.

This older helper snapshot is retained with its source attribution, but it is not linked into the restored Native Media3 engine and is not copied into the current MPV runtime. The experimental MPV runtime checks out native FongMi/mpv commit [`14b3999a1a3e322c217bc90ee4df5a8f1bc88f69`](https://github.com/FongMi/mpv/tree/14b3999a1a3e322c217bc90ee4df5a8f1bc88f69) directly. The pinned upstream `video/out/gpu_next/motion.c` receives version-guarded, app-owned refinement, synthesis, reconstruction, inverse-warp, and analysis-sampling changes through `scripts/patch_fongmi_motion_artifact.py` before build. Existing safeguards check local flow coherence at likely seams, attenuate trust at luma/chroma boundaries, extend the color-error trust fade through `0.30`, and cap directional softening to supported moving regions. In strongly anisotropic structure-tensor patches, refinement adjusts only the principal-gradient component while retaining the inherited tangential motion estimate; well-textured and corner patches retain their measured two-dimensional flow. Inverse-warp recovery retains the initial position and updates, then selects the finite candidate with the best forward-closure residual while preserving existing support, cycle, and confidence gates. Unsupported motion retains the source-frame crossfade. The new downsample experiment averages bounded bilinear sub-block centers before matching; for a 1920x1080 input reduced to the unchanged 480x270 analysis image, it averages each 4x4 source footprint while retaining the existing three-level motion pyramid and vector-grid spacing. This may reduce temporal aliasing on thin detail, but adds work to the capture/downsample pass and is not visually or performance-validated on device. The active pinned source is validated by `scripts/prepare-mpvflow.py`; this transform does not replace FongMi source. The retained snapshot mirrors safeguards for regression checks but is not the build patch source. FongMi's GPL-2.0 attribution and full upstream `LICENSE.GPL` text remain preserved in `app/src/main/assets/mpv/licenses/` alongside all upstream per-file notices.

Keep this attribution and each source-file notice with the retained code. This branch remains experimental, unmerged, and unreleased.
